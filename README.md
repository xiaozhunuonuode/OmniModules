# 小朱诺诺的 Omni 模块

适用于 Omni Toolbox 的在线模块仓库，不是独立 Dalamud 插件仓库。

update v1.1.1：移除商城签到及相关代码，保留石之家自动签到、领奖和现有卡片界面，精简“更多操作”。

- 登录后自动完成石之家每日签到，并领取当月达到条件的奖励。
- 保留现有卡片、按钮和主题样式，改为单栏布局。

### 安装与更新

在 Omni 的“插件设置 → 在线模块”中添加此仓库：

```text
https://github.com/xiaozhunuonuode/OmniModules
```

已订阅的用户刷新现有仓库，不要重复添加。自动更新下载已安装模块的新版本，下次启动 Omni 时应用。首次安装后在“树树妙妙屋 → 在线”中启用模块。若曾卸载模块，普通刷新不会自动重新安装，需要重新添加该仓库；无须清除账号配置。

当前清单最低 Omni 版本为 **1.1.4.4**，按本次构建验证基线设置。请先更新 Omni；这不表示所有更高版本均已实测。同名本地版和在线版不要同时加载。

### 日常使用

点击“登录石之家”，在新开的独立 Edge／Chrome 窗口中完成官网登录。密码和验证码只在官网填写。登录过期后点击“更新登录”，不会反复自动弹窗。

模块启用且保存账号后自动运行，停用模块即可停止后续自动操作。每 60 秒检查本地条件，不等于每分钟访问网站；游戏角色已登录、非战斗／切图、冷却到期时才推进流程。当天完成后不再自动联网。关闭设置界面不影响自动运行。

在“更多操作”中可查看当月签到及每项奖励的已领取／可领取／未达标状态，或按需刷新、查看运行记录。

### 升级与数据

公开入口仍为 `RisingStonesAutoCheckIn`，显示名称改为“石之家每日签到”。石之家账号文件 `LocalModules/RisingStonesAutoCheckIn.json`、加密格式和处理记录保持不变，无需重新导入账号。

商城的登录、签到、后台请求、界面和调试代码已移除。旧商城账号文件保留，但本模块不再读取它或访问商城。用户另外安装的独立商城模块不受本次更新管理。

### 隐私与信任边界

浏览器登录使用本轮独立临时资料目录，不读取日常浏览器资料。正常结束时关闭本次窗口并尝试清理；异常退出可能留下临时资料，请留意提示。不要在临时窗口登录浏览器同步账号或浏览无关网站。

登录凭据由 Windows 当前用户 DPAPI 加密保存在本机。不要公开账号配置、Cookie、请求头或原始响应。本发布包不包含用户账号或浏览器资料。同一 Windows 用户权限下的其他程序仍可能解密，DPAPI 不能防御本机恶意程序。

在线模块与 Omni 具有相同权限，没有独立沙箱。自动更新意味着继续信任此仓库后续代码。SHA256 用于下载完整性校验，不是第三方安全认证。

### 验证范围

发布前重新执行 **4106 项离线功能检查、95 项静态接线检查、286 项原生 ImGui 布局检查**；严格 Release 构建为零警告、零错误。界面检查覆盖宽窄窗口、150%字体和明暗主题。

这些检查使用合成账号和响应，没有执行真实网站签到／领奖，也不代表完整的游戏内或线上迁移实测。
