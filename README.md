# 小朱诺诺的 Omni 模块

适用于 Omni Toolbox 的在线模块仓库，不是独立 Dalamud 插件仓库。

## 石之家每日签到 1.2.3

update v1.2.3 优化签到推送文案，精简冗余提示，多账号结果分行显示。

- 保存多个账号，分别启用、暂停、备注和更新登录；自动签到与领奖串行处理。
- 账号卡片默认收起，点击名字或箭头展开；常驻显示状态与启用开关。添加／更新登录轻微强调，移除使用柔和警示色。
- 宽窗口左侧账号、右侧共享通知，窄窗口自动上下排列；“更多操作”统一选择账号查看详情。
- 游戏聊天每日汇总，Server酱通知可选；使用备注或账号编号，不自动发送角色名。

### 安装与更新

在 Omni 的“插件设置 → 在线模块”中添加此仓库：

```text
https://github.com/xiaozhunuonuode/OmniModules
```

已订阅的用户刷新现有仓库，不要重复添加。自动更新下载已安装模块的新版本，下次启动 Omni 时应用。首次安装后在“树树妙妙屋 → 在线”中启用模块。若曾卸载模块，普通刷新不会自动重新安装，需要重新添加该仓库；无须清除账号配置。

当前清单最低 Omni 版本为 **1.1.5.6**，按本次构建验证基线设置。请先更新 Omni；这不表示所有更高版本均已实测。同名本地版和在线版不要同时加载。

### 日常使用

点击“添加账号”，在新开的独立 Edge／Chrome 窗口中完成官网登录，确认角色后保存。密码和验证码只在官网填写。原角色登录过期后展开卡片点击“更新登录”；其他角色请用“添加账号”。不会反复自动弹窗。

模块启用且保存账号后自动运行，停用模块即可停止后续自动操作。空闲账号最多每分钟检查一次本地条件，不等于每分钟访问网站；游戏角色已登录、非战斗／切图、冷却到期时才推进流程。网站操作在账号之间串行推进；账号当日完成、明确登录失效或被暂停时，不继续该账号的自动网站请求。收起账号或关闭设置界面不影响自动运行。

账号不设固定个数上限，每页展示四个。各账号独立折叠，分页／调整窗口大小保留展开状态，重新加载时默认收起；刚添加的账号保持展开。在“管理”中可改备注、查看详情或确认移除该账号。

在共享“更多操作”中选择账号，可查看当月签到及奖励状态，或按需刷新、查看运行记录。

### 通知设置

默认关闭。打开“签到结果通知”，填入 Server酱的完整 **API URL**，回车或移开焦点保存；同一套设置管理全部账号。支持 Server酱³ `https://<uid>.push.ft07.com/send/<sendkey>.send` 和 Turbo `https://sctapi.ftqq.com/<sendkey>.send`，不能只填 SendKey。

- 按北京时间汇总已保存且启用的账号，包括签到已确认、待登录、未完成、待核实、等待、未运行及今日已确认奖励数。奖励数是本机今日确认的奖励项数，不是道具数量或历史累计。
- 所有账号有本轮结果时发送；仍有账号等待时，从符合条件的本地检查开始最多聚合十分钟。原汇总账号后续恢复或结果确定，可追加最多一条更新，每天至多两条。
- 游戏聊天只显示简短摘要，不依赖推送开关。手机推送显示备注或账号编号，最多展开前24个账号，其余计入总数；不要在备注里写敏感内容。
- 开启通知不会补发旧事件。发送失败不影响签到，也不会自动重发；服务端接收不保证手机已经显示。

1.2.3 的手机通知只保留相关结果：单账号正常时为“账号 1，今天已签到。”，有备注则显示备注；多个账号分行展示。只有当天确认领取的奖励大于0才显示奖励数量，登录过期、未完成或待确认时才附对应说明。日期不再附“北京时间”，但业务日仍按北京时间计算。未改变游戏聊天、签到／领奖、通知时机或每日发送次数。

Server酱配置参考[官方使用说明](https://doc.sc3.ft07.com/zh/serverchan3)。API URL 含推送密钥，输入框默认掩码显示；点击标题右侧“显示原文”查看，再点“隐藏”恢复掩码。显示状态不保存，停用或重新加载模块后恢复隐藏。地址仍使用当前 Windows 用户 DPAPI 加密保存，切换不改变通知规则；显示时注意截图／直播，请勿分享。

填好地址后，点击底部“测试发送”即可向当前输入的地址发送一条“石之家通知测试”。无需开启每日通知，也不要求先添加账号；测试不触发签到、不占模块每日汇总次数，但属于 Server酱的一次发送。发送中按钮暂时禁用，最多等待十秒，结果在下方显示一行。出现“服务已接收，请查看手机通知”后请检查接收端；失败时检查地址或网络后可再点，不会自动重试。停用模块、关闭通知或提交地址修改会取消未完成测试并清除旧测试反馈，已发出的通知无法撤回。

### 升级与数据

公开入口仍为 `RisingStonesAutoCheckIn`，显示名称“石之家每日签到”。首次没有新配置时，自动从 `LocalModules/RisingStonesAutoCheckIn.json` 迁入 `LocalModules/RisingStonesAccounts.json`，保留原账号登录资料和处理记录，无需重新导入。旧文件保留且不修改，新文件存在时不会重复迁移；新文件损坏时停止读取，不用旧记录覆盖。

旧版不会读取新账号列表，回退会使用迁移前记录，请勿来回混用。暂停账号不删除记录，移除仅删除选中账号的当前本机记录；旧迁移文件仍可能包含历史登录资料副本。

商城的登录、签到、后台请求、界面和调试代码已移除。旧商城账号文件保留，但本模块不再读取它或访问商城。用户另外安装的独立商城模块不受本次更新管理。

### 隐私与信任边界

浏览器登录使用本轮独立临时资料目录，不读取日常浏览器资料。正常结束时关闭本次窗口并尝试清理；异常退出可能留下临时资料，请留意提示。不要在临时窗口登录浏览器同步账号或浏览无关网站。

登录凭据由 Windows 当前用户 DPAPI 加密保存在本机；配置中的备注、角色展示名和业务状态不是整文件加密。不要公开账号配置、Cookie、请求头或原始响应。本发布包不包含用户账号或浏览器资料。同一 Windows 用户权限下的其他程序仍可能解密，DPAPI 不能防御本机恶意程序。

在线模块与 Omni 具有相同权限，没有独立沙箱。自动更新意味着继续信任此仓库后续代码。SHA256 用于下载完整性校验，不是第三方安全认证。
