# 小朱诺诺的 Omni 模块

适用于 Omni Toolbox 的在线模块仓库，不是独立 Dalamud 插件仓库。

## 石之家 / 商城每日签到 1.1.0

- 石之家每日签到、领取当月达到条件的奖励。
- 盛趣商城每日积分签到。
- 两个账号区域独立管理；窄窗口自动上下排列。
- 共用“更多操作”，按石之家／商城页签查看状态和调试信息。
- 浏览器登录后自动运行。首次或更换账号确认一次，原账号更新后自动继续。

**升级前请停用旧的独立“商城自动签到”模块，避免两份模块同时使用商城账号记录。** 同名的本地版和在线版也不能同时加载；切换时移除旧模块条目即可，不需要清除账号。

### 安装与更新

在 Omni 的“插件设置 → 在线模块”中添加此仓库：

```text
https://github.com/xiaozhunuonuode/OmniModules
```

已添加过仓库的用户，在现有仓库行刷新即可，不要再次点“＋”添加同一个地址。自动更新下载已安装模块的新版本，下次启动 Omni 时应用。首次安装后在“树树妙妙屋 → 在线”中启用模块。

当前清单最低 Omni 版本为 **1.1.3.4**，这是本次构建验证基线，不表示所有更高版本均已实测。更新宿主仍可能影响兼容性。

### 日常使用

在对应账号区域点击“登录石之家”或“登录商城”，于打开的独立 Edge／Chrome 窗口完成官网登录。密码和验证码只在官网填写。登录信息过期后，点击“更新登录”重新登录即可，不会反复自动弹窗。

模块启用且保存账号后自动运行，不需要额外开启自动选项。停用模块即可停止两站后续操作。当天完成后不再为该站点自动联网；“更多操作”中的刷新、运行记录与手动操作仅在核对或排错时使用。

每 60 秒检查本地运行条件，不等于每分钟向两个网站发请求。游戏角色已登录、非战斗／切图、冷却到期时才推进对应站点未完成的流程；两站保留各自的次数与冷却。只有一个宿主检查回调，关闭设置界面不影响自动运行。

### 本次变化与迁移

原石之家模块入口仍为 `RisingStonesAutoCheckIn`，仅显示名称改为“石之家 / 商城每日签到”，并将商城作为内部控制器合入。两站各自的旧账号文件和加密格式保持不变：

- `LocalModules/RisingStonesAutoCheckIn.json`
- `LocalModules/MallAutoCheckIn.json`

备用输入入口、相关解析代码和提示已移除，现在只保留浏览器登录。首次或不同账号仍需确认；原账号更新保留原有处理记录。浏览器窗口一次只处理一个站点，取消后的收尾期间也会等待。

升级后请核对两边账号是否正确显示。如果账号文件读取异常，对应站点会提示重试，不会覆盖损坏文件，也不会阻断另一站点。

### 隐私与信任边界

模块不读取日常浏览器资料；浏览器登录使用本轮独立临时资料目录。正常结束时关闭本次窗口并尝试清理；异常退出可能留下临时资料，请留意提示。不要在临时窗口登录浏览器同步账号或浏览无关网站。

登录凭据以 Windows 当前用户 DPAPI 加密保存在本机，账号展示信息和签到记录也仅保存在本机。不要公开账号配置、Cookie、请求头或原始响应。本发布包没有用户账号或浏览器资料。同一 Windows 用户权限下的其他程序仍可能解密，DPAPI 不能防御本机恶意程序。

在线模块与 Omni 具有相同权限，没有独立沙箱；请仅信任你愿意授权的来源。自动更新意味着继续信任此仓库后续代码。SHA256 只用于下载完整性校验，不是第三方安全认证。

### 验证范围

发布前重新执行 4777 项合成离线检查和 92 项静态接线检查，严格 Release 构建无警告／错误。共享界面另通过 140 项原生 ImGui 布局检查，覆盖宽窄窗口和字体缩放。

这些检查未使用真实账号或提交网站签到／领奖，不能代替完整的游戏内和官网场景验收。真实登录、在线升级迁移及可领奖励到期后的领取结果仍需实际核对。
