# 小朱诺诺的 Omni 模块

适用于 Omni Toolbox 的在线模块仓库，不是独立 Dalamud 插件仓库。

## 安装

在 Omni 的“插件设置 → 在线模块”中填入：

```text
https://github.com/xiaozhunuonuode/OmniModules
```

点击右侧“＋”，安装后在“树树妙妙屋 → 在线”中手动启用模块。首次安装默认关闭；是否启用自动更新由你决定。

当前清单要求 Omni 1.1.3.3 或更新版本。1.1.3.3 是本次验证使用的构建基线，不代表已验证所有更新版本或证明旧版本不兼容；更新宿主也可能影响兼容性。

## 石之家自动签到 1.0.3

- 启用模块并保存账号后，自动签到、领取当月可领奖励；当天全部完成后停止自动联网。停用模块即可停止后续操作。
- 在“账号设置”点击“浏览器登录”，于本次打开的独立 Edge/Chrome 窗口自行完成官网登录；密码、验证码只在官网填写。
- 首次添加或更换角色，验证成功后核对候选角色并确认保存一次。已保存的原角色重新登录成功后，自动更新登录信息、查询状态并恢复签到领奖，不再需要逐项点击更新、刷新和恢复。验证接口本身只读，后续业务由启用中的后台流程执行。
- 浏览器登录仅在点击后运行，最长等待5分钟。未取得所需登录信息时仅查询本次浏览器；账号验证尚未确认登录时，至少等待30秒再读取并验证，最多10次。成功、取消、限流、拦截或其他错误会结束。备用 cURL 导入保留在折叠选项中。
- 如遇问题，反馈模块显示的阶段、次数或错误提示即可，不要发送Cookie、完整cURL、请求头、原始响应或账号配置。

### 本次更新

- 业务码10105和10403按登录失效处理，提示重新登录；10105为兼容处理策略，不是对官方网站码表的确认。
- 原角色自动续更采用新鲜验证结果中的角色、大区、服务器完整匹配，并核对本机绑定上下文；不是按昵称匹配，也不宣称旧配置拥有网站唯一账号ID。保留原绑定、记录、次数与冷却。
- 已更新登录信息但等待核验的旧状态，重载新版后也会自动继续。每60秒检查本地条件，角色在线、非战斗/切图且冷却到期才联网；核验失败且未明确过期时至少间隔5分钟重查，网站要求更久则等待，重载不绕过间隔。明确过期后停止，等待用户重新登录，不会反复弹浏览器。
- 领奖超时或结果未确认不再形成永久本地锁。后续轮次重新查询，仍可领取才尝试；同轮同一奖励最多提交一次。签到的未知结果仍需核对，不会凭缺少记录就认作成功。
- 登录只读核验不占业务轮次；签到领奖仍每天最多3轮，轮间至少5/30分钟，已用满等次日。当天已完成不因重新登录被重开。想停止时停用模块即可。

### 从本地版切换

同名的本地版与在线版不能同时安装。切换时先停用本地版、移除对应的本地模块条目，再安装在线版；不要点击模块内的“清除已保存账号”。

此版仍使用 Omni 配置目录中的 `LocalModules/RisingStonesAutoCheckIn.json`，不因在线下载目录改变而更改账号文件路径。首次迁移后请核对账号是否保留；如异常，先停用并反馈，不要删除配置来排错。

### 隐私与信任边界

模块不会读取日常浏览器资料；浏览器登录使用本轮独立临时资料目录，正常结束时关闭本次窗口并尝试清理。不要在临时窗口登录浏览器同步账号、保存密码或浏览无关网站。异常退出或清理失败可能残留本轮临时资料，模块会尽可能提示。

登录信息使用 Windows 当前用户范围的 DPAPI 加密保存在本机；角色显示资料、签到与领奖记录等配置也保存在本机。本发布包不包含任何用户的账号配置、Cookie、浏览器资料或密码。同一 Windows 用户权限下的其他程序仍可能解密，不能据此防御本机恶意程序。

在线模块拥有与 Omni 相同的运行权限，没有独立沙箱；只安装信任的来源。自动更新意味着继续信任该仓库后续发布的代码。DLL仍可被检查或反编译，不等于隐藏源码的安全措施。

## 发布与更新

仓库根目录必须保留 `TreeHouseModules.json`。清单的 `File` 指向仓库中的版本化DLL文件；不能改成Release附件或ZIP。

后续发布请使用新的版本目录，提高清单的 `Version`，重新计算新DLL的 `Sha256`，并把模块文件与清单一起提交。不要覆盖旧版本目录却不提高版本号。Omni下载后校验文件字节，哈希不一致会拒绝安装。

Omni启动时及每6小时刷新清单，也可以手动刷新。自动更新下载已安装模块的更高版本，在下次启动Omni时应用；仅修改哈希但不提高版本号，不会更新已安装模块。

以上安装格式与更新行为以[Omni官方在线模块说明](https://github.com/YouShux/OmniToolbox.TreeHouseOnline)为依据。
